# SERP Nook - Free SERP Preview & Meta Tag Generator

See how your page will render on Google, Bing and social cards - side by side,
with truncation shown the way each engine actually cuts it.
**100% client-side. No account. No tracking. Free forever.**

## Features

- Live Google + Bing search result previews (side by side)
- Open Graph / Twitter card preview with image slot
- Character counters with warning thresholds (60 / 160 / 70 / 200)
- Copy-paste ready HTML meta tags
- Works offline (PWA)

## Privacy

Everything is simulated in the browser - no URL is ever fetched, no data leaves the device.

## Run it

Open `index.html` in a browser - or host anywhere static
(Vercel, Netlify, GitHub Pages, Cloudflare Pages).
